# 三国狼人杀

> 从 219 位三国豪杰中随机选拔 15 人，进行狼人杀智谋对决。纯前端，浏览器打开即玩。

## 快速开始

**零依赖，打开即玩：**

```bash
# 克隆仓库
git clone https://github.com/ljq695543881/three-kingdoms-agent.git
cd three-kingdoms-agent

# 用浏览器打开
open werewolf.html        # macOS
# 或直接双击 werewolf.html
```

仅 `werewolf.html` + `characters_data.js` + `avatars/` 即可运行，无需任何服务器或构建工具。

## 游戏说明

- **玩法**：经典狼人杀规则，4狼 vs 好人阵营（预言家、女巫、猎人、守卫、7平民）
- **角色**：每局从 219 位三国人物中随机抽取 15 人，角色随机分配
- **视角**：上帝视角，观看 AI 自动推演发言、投票、夜间行动
- **交互**：暂停/继续按钮控制游戏节奏

## 人物百科

本仓库同时收录了三国时期 219 位历史人物的详细百科档案（Markdown 格式），每位人物包含：

- **人物简介**：生平概述与主要事迹
- **性格特征**：核心性格标签与解读
- **核心技能**：标志性能力与专长
- **属性标签**：六维能力评估（武力 / 智谋 / 统帅 / 政治 / 魅力 / 意志）
- **语录全集**：区分正史记载与文学创作
- **历史评价**：陈寿评语、同代人评价与后人评述
